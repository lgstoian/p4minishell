# Native payload host fixtures (test-only)

Everything here is a **host test fixture**, never a device trust key and never
a shipped payload.

- `demo.c` — smallest fixed-ABI payload: a `.p4ex.exports` section with two
  entry offsets and one dummy entry. Built by
  `tools/make_native_payload.py build --source demo.c ...`.
- `testkey.priv.pem` / `testkey.pub.bin` — a throwaway P-256 pair generated by
  `tools/pkg_sign.py keygen --out testkey`. It is *not* installed on any board;
  firmware trusts only the single `p4sign` NVS key.
- `demo.P4X` — a signed example envelope built from `demo.c` with `testkey`.

Regenerate (from the repository root):

```powershell
python tools/pkg_sign.py keygen --out tools/host/fixtures/native/testkey
python tools/make_native_payload.py build --source tools/host/fixtures/native/demo.c `
  --out tools/host/fixtures/native/demo.P4X `
  --key tools/host/fixtures/native/testkey.priv.pem `
  --api console,env --entry 0 --check
python tools/make_native_payload.py selftest
```

`check`/`verify` never map or run the payload bytes; the red canary proves the
checker refuses tampering (magic, version, size, CRC, SHA-256, signature,
reserved field, API bits, ordinal, ELF magic, entry offset).
