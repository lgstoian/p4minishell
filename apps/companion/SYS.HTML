P4 Companion - System Guide

This page is a local file (DOCS/SYS.HTML) opened by the html verb. No access point, cloud service or HTTP server is involved.

What the dashboard shows

  • Memory: internal heap, DMA pool, tasks and the 32 MB PSRAM pool.
  • Tasks: the shell worker, display, services and background jobs.
  • Services: resident batch jobs supervised across reboots.
  • Packages: apps installed from a PKGS bundle.

Where the app keeps its data

Every path below uses the app drive, so the same page describes an SD or a USB install. The shell publishes that drive to batch apps as %APPDRIVE%.
